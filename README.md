# 🐾 Pet Adoption Web Application

## 📌 Project Overview
This is a pet adoption web application built using Node.js, Express, and MongoDB.  
It allows shelters to manage pet listings and adopters to browse and interact with available pets.

---

## ⚙️ Setup Instructions

### 1. Install dependencies
Run the following command in your terminal:

```bash
npm install
```

---
## ▶️ How to Run the Application

Start the server using:

```bash
nodemon app.js
```
OR
```bash
node app.js
```

Then open your browser and go to:

http://localhost:8000/index.html
